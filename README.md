# Sytothapp 🌡️📅
# Not finished !!
**A Privacy-Focused Sympto-Thermal Method (STM) Tracker for Android**

Sytothapp is an open-source Android application designed to empower users with **fertility awareness** through the **Sympto-Thermal Method (STM)**. It prioritizes **privacy, accuracy, and simplicity**, helping users track their menstrual cycles, basal body temperature (BBT), cervical mucus, and other fertility indicators to identify their **fertile window** with confidence.

---

## ✨ **Key Features**
- **Basal Body Temperature (BBT) Tracking**: Log and visualize daily temperature readings to detect ovulation.
- **Cervical Mucus Observation**: Track changes in cervical mucus consistency for fertility insights.
- **Cycle Visualization**: Interactive charts to monitor trends and patterns in your cycle.
- **Privacy-First**: All data is stored **locally** on your device—no cloud sync, no third-party access.
- **Customizable Reminders**: Set notifications for temperature logging and other observations.
- **Open Source**: Transparent, community-driven development under the [MIT License](#license).

---

## 📱 **Why Sytothapp?**
- **Natural Family Planning**: Ideal for those using STM for contraception or conception.
- **No Ads, No Tracking**: Built with respect for your privacy.
- **Offline-First**: Works without an internet connection.
- **Science-Backed**: Based on the **Sympto-Thermal Method**, a well-researched fertility awareness technique.

---

## 🛠️ **Tech Stack**
- **Language**: [Kotlin](https://kotlinlang.org/) (100%)
- **Platform**: Android (Min SDK: 24+)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Dependencies**:
  - [Jetpack Compose](https://developer.android.com/jetpack/compose) for UI
  - [Room](https://developer.android.com/training/data-storage/room) for local database
  - [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart) for data visualization

## 🚀 **Getting Started**

### Prerequisites
- Android Studio (latest version)
- Android SDK (API 24+)
- Kotlin plugin

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Widnax/Sytothapp.git
   ```
2. **Open in Android Studio**:
   - File → Open → Select the `Sytothapp` directory.
3. **Build and Run**:
   - Sync Gradle and build the project.
   - Run on an Android emulator or physical device (API 24+).
